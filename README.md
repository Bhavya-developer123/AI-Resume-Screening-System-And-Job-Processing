# AI Resume Screening & Job Matching System

An AI-powered full-stack application for resume screening and job matching.

## Overview

The system allows candidates to upload resumes and compare them with job descriptions using Natural Language Processing and AI-based matching techniques.

It extracts resume information and skills, processes job descriptions, calculates matching scores, identifies skill gaps, and provides recommendations.

Recruiters can create jobs, view candidates, and rank candidates based on match scores.

## Features
