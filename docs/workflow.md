# Application Workflow

## Candidate Workflow

```text
Register
   ↓
Login
   ↓
Upload Resume
   ↓
Resume Validation
   ↓
Resume Processing
   ↓
Extract Information
   ↓
Extract Skills
   ↓
View Available Jobs
   ↓
Select Job
   ↓
Analyze Resume
   ↓
AI Matching
   ↓
Match Score
   ↓
Matched Skills
   ↓
Missing Skills
   ↓
Skill Gap
   ↓
Recommendations
   ↓
View Result
```

## Recruiter Workflow

```text
Register/Login
      ↓
Recruiter Dashboard
      ↓
Create Job
      ↓
Add Job Description
      ↓
Add Required Skills
      ↓
Add Preferred Skills
      ↓
Publish Job
      ↓
View Candidates
      ↓
View Match Scores
      ↓
Rank Candidates
```

## AI Matching Workflow

```text
Resume
   +
Job Description
       ↓
Text Processing
       ↓
Skill Extraction
       ↓
Skill Normalization
       ↓
Skill Matching
       +
TF-IDF Matching
       +
Semantic Matching
       ↓
Hybrid Score
       ↓
Skill Gap Analysis
       ↓
Recommendations
```
